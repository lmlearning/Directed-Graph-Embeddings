# Directed Graph Embeddings

A research collection on **directed graph embeddings and graph representation learning**.

## Start here

Read the [literature-review overview](literature_review/README.md), then browse the [paper summaries](literature_review/paper_summaries/).

The repository organizes literature and research notes. It is a reading resource rather than a packaged graph-embedding library. Consult the original publications for authoritative methods, results and attribution.
